# NutriPlan

A free, fully client-side diet helper — no backend, no sign-up. Open `index.html` through any static server (`python3 -m http.server`).

- Calculates daily calories, carbs, protein and fat (Mifflin–St Jeor) for lose / maintain / gain goals
- Builds a 7-day meal plan sized to your numbers, with swap and regenerate
- 76 original recipes (vegetarian and vegan filters), each with scaled ingredients, method and macros
- Tick the ingredients you have at home to get recipes ranked by what you can already make

Estimates only — not medical advice.
