NutriPlan photo helper

Makes one photo per recipe and saves it as photos/<id>.jpg, then updates photos/index.json. Open this page from a local server in the food repo (python3 -m http.server, then http://localhost:8000/tools/photo-helper.html) in Chrome or Edge.

No folder chosen: images will download one by one instead (browsers without folder access).

Automatic: Gemini API

Uses an official Google AI Studio API key (not your Gemini web account). The key stays in this page and is sent only to Google. Image generation may be billed by Google; check your quota and set a spending limit first.

Idle.

Manual: use the Gemini app yourself

Copy the prompt, paste it in Gemini, then drop the image you download here. The page names it and saves it, then moves to the next recipe.
